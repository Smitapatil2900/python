🏦 Banking Transactions Analysis Using MySQL

A SQL-based data analysis project exploring banking transactions, customer activity, and transaction trends.

📌 Project Overview

This project uses MySQL to analyze banking transaction data and explore patterns in customer activity and transaction behavior. It demonstrates how SQL can be used to organize, query, and analyze relational data to support data-driven decisions.

🎯 Project Objectives

* Explore customer and transaction records.
* Analyze transaction volume and value.
* Understand activity across transaction and account types.
* Identify customers with high transaction activity.
* Compare transaction trends over time.
* Apply practical SQL techniques to a banking dataset.

🧰 Tools & Technologies

Database name: banking_analysis

Table	Description
